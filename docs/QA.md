# 本機驗證紀錄

日期：2026-10-03。驗證範圍是本機 Node 網站，非公開部署或真人學習成效研究。

## 學習資料與引擎

- 7,000 個唯一詞目；異體拼法合併為別名。中英釋義均非空，英英釋義未混入中文字。
- 使用真正 `data.js`／`vocabulary.js`，模擬依序完成 100 關、740 小任務；第 20／40／100 關分別為 1,200／2,000／7,000 字，70,000 XP。每關後 strict 載入存檔，結果見 `curriculum-verification.json`。
- 單元測試區分新字獲得、錯題重排、到期複習、熟練度、重複給分及損壞備份。

## Chrome 實際操作

- 全英第一任務：閱讀 10 張卡片，完成字義與拼字測驗，得到 10 字／100 XP。
- 舊版流程實測故意答錯後題目重排；下一任務必須先複習上一段 10 字。兩分頁學習進度同步與中斷未完成練習已驗證。
- 故事：選擇地圖繪製者，第一個事件選擇等待狐狸靠近，善意增加 1。重新登入後角色與選擇仍在。
- 繁中與英文首頁、手札、字卡、故事、測驗及語音偏好可操作。英文模式詞性已由「名詞」修正為 `noun`；學習中的語系切換鎖定並說明原因。
- 手機實測 `innerWidth=390`、內容區寬 376（含桌面捲軸），`scrollWidth=376`，沒有水平溢出；另測較窄 355 寬度。角色、里程碑與地圖可見。
- 旅程 JSON 備份實際下載至 Downloads，讀回 10 詞／100 XP／英文／角色／一項選擇。再於 `?test=1` 獨立存檔透過檔案選擇器匯入，手札顯示 10 詞／100 XP。

## 登入與伺服器

- Google Cloud 控制台核對既有用戶端已授權的 `http://localhost:8787`，沿用該用戶端，未修改其他網站的 OAuth 設定。
- 真實 Google 帳戶登入成功；SQLite 只讀回查（不輸出帳號、email 或 token）確認 10 詞／100 XP／角色／一個選擇／英文。
- 伺服器重新啟動後 session 仍有效。登出切回獨立訪客紀錄，再登入還原原帳戶 10 詞、100 XP、角色與善意 1。
- API 自動測試使用注入的測試 token verifier；真實 Google 驗證另由上述 Chrome 流程證明。
- 靜態 HTTP 請求 `.env` 與 `data/progress.sqlite` 均回 403。
- 曾發現新裝置空檔覆蓋角色、換帳號挾帶前帳號資料、API 接受不完整冒險資料；已加入共用驗證與回歸測試。跨分頁帳號切換另設專項回歸：本分頁 owner、延遲 storage／cookie／回應、expectedAccountId 與請求帳號錯配拒絕。

## 語音與圖像

- 6,148 個 MP3 的來源與副本 SHA-256 全數相符，總 56,587,424 bytes。852 個詞使用裝置語音。
- HTTP 讀回範例 `letter`：200、`audio/mpeg`、8,732 bytes，回應 SHA 與磁碟相同。
- Chrome 按單字朗讀後出現「Reading…」，單字、文章、自然／英式與慢速控制皆可操作，沒有相關 console error。這不等同逐字人工聽審。
- 語音測試涵蓋 MP3 失敗回退、英式聲線缺失、延後載入聲線、停止、舊回呼取消與逐句閱讀。
- 10 張章節圖集，每張 5×2；100 格對應 100 關故事。10 個 SHA 皆不同，每張 1,983×793，合計 32,218,177 bytes。另有主視覺、三角色圖集、六事件場景圖集。
- 圖像代理逐張驗視；根代理另直接驗視第一與最後圖集，以及 Chrome 第一章閱讀卡與角色呈現。詳細圖檔清單見 `chapter-art-audit.json`。

## 驗證限制

- 單字、英英釋義、例句與合成語音尚未全量人工教學／聽審；多音字與字典義項仍需持續精修。
- 72 個詞附例句；100 篇文章不代表已替全部 7,000 詞提供例句。
- 100 關以引擎模擬驗證，沒有逐關進行人工瀏覽器通關。後 60 篇採部分共用敘事結構。
- SQLite 目前在本機。公開部署與真正跨裝置使用仍待正式主機、持久資料庫及正式 OAuth origin 設定。
