# 沉浸地圖驗證

日期：2026-10-03。本波回應「背景圖呢？我需要沉浸感」，只調整地圖圖像與呈現，不變更學習進度、解鎖條件或帳號資料。

## 素材

- 以內建 image_gen 製作 10 張獨立的英式水彩地景，每張 1774×887，合計 37,630,425 bytes。全部為原始 PNG，未經裁切或修圖。
- 專案路徑：`assets/map-region-01.png` 至 `assets/map-region-10.png`。
- 每 10 關對應一區：科茲窩、牛津、倫敦、劍橋、約克、湖區、峰區、愛丁堡、蘇格蘭高地、歸途。
- [01–05 完整提示與來源](map-art-early.md)、[06–10 完整提示與來源](map-art-late.md)。圖像是敘事風景，不是精準地理地圖；互動路線為獨立的介面圖層。
- [檔案稽核](map-assets-audit.json)：10 個相異 SHA-256；本機 HTTP 回讀全部 200、PNG MIME、位元組雜湊一致。

## 實際驗證

- 直接受影響的兩個地圖測試、`node --check app.js`、`git diff --check` 通過；里程碑最終全套 `npm test` 共 51 個測試通過。
- 獨立 Node harness 載入實際地圖函式：0→1→2 快速切區後，舊區成功或失敗均不覆蓋最後區域；載入中的重複 render 不重送；失敗後同區 render 可以重試並恢復 ready。備援與 aria-busy 狀態正確。
- 獨立瀏覽器測試分頁逐一切換 10 區：背景全部成功載入，每區 10 個路標，涵蓋 100 關。
- 390px 英文版：頁面內容寬度與可用寬度均為 376px，整頁沒有水平溢出；地圖可用寬度 335px，內部畫布 760px。鍵盤聚焦第 90 關會自動移動地圖到右側。
- 1024px 英文版：地圖單欄；第一路標左側保留 15.7px，第九路標底部保留至少 22.2px，完整容納 7px 焦點外框。
- 1290px 英文版：桌機雙欄交界，畫布 682.6×380px；第一路標左側保留 8.1px。牛津第 19 關長標題底部保留 10.2px，焦點外框完整。
- 390px 下逐區檢查全部英文路標，最小底部空間 10.2px。桌機畫布最小高度設為 380px，避免長標題底部裁切。
- 桌機繁中、平板英文、手機英文已目視截圖確認；測試分頁沒有捕捉到 console error。

截圖位於本機忽略提交的 `artifacts/map-desktop-zh.jpg`、`artifacts/map-tablet-en.jpg`、`artifacts/map-mobile-en.jpg`；逐區瀏覽器輸出為 `artifacts/map-regions-browser.json`。測試結束已清除裝置尺寸模擬並恢復繁中；未操作使用者原分頁進行中的練習。
