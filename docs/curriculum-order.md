# 詞彙排序與學習階段

本版把 7,000 個學習目標排成「生活入門 → 國中核心 → 國中延伸 → 高中銜接 → 高中中階 → 高中進階」的連續詞序。來源標籤保留官方出處；難度帶是本專案的課程編排。官方詞表級別並不保證某個年齡一定學得會，也不能直接換算成 CEFR。

本次編選由模型整理，尚未經真人教師逐詞驗收。

## 可追溯的資料契約

- `sources/curriculum-order.json`：`version: 1`、恰好 7,000 個不重複 ID 的 `order`、每個 ID 的 `bands`（1–6）及 `rationales`。
- `notes.curatedReadinessGroups` 記錄入門 300 詞的編輯分組；`notes.essentialFunctionIds` 記錄必須提早出現的功能詞；`notes.supplementSemanticAssignments` 記錄補充詞編輯分帶。
- `sources/curriculum-replacements.json`：13 組拼字別名與 13 個新增詞的完整編輯資料。產生最終詞庫時，先把 `aliases` 併入保留目標，再移除別名的獨立 ID，加入 `words`，最後套用 `order`、`bands`。
- 同一目標已有的別名必須保留，例如 `e-mail`、`good-bye`、`o’clock`；不能用新的 13 組別名覆蓋原有陣列。
- 這兩份 JSON 是本波的課程資料來源。此文件不宣稱應用程式、存檔遷移或網站部署已整合完成。

### 入門 300 詞的性質

[國教院的英語文課綱資料](https://www.naer.edu.tw/PageMain5/projectDetail/RP000000001141)指出國小至少 300 字及國中至少 1,200 字的學習量。本專案沒有把這個最低數量宣稱為「官方唯一國小 300 字名單」。前 300 詞是編輯編選的準備詞彙，涵蓋人稱、基本問句、日常動作、家人、數字、顏色、食物、身體、物品、交通、自然、感受、位置、時間與禮貌。

前 60 個詞的 ID 與原順序完全保留，避免改動已存在的第 1 關進度契約。其餘 240 詞依生活主題排列；不是從全域詞頻表截取前 300 名。因此 `me`、`my`、`him`、`us`、`them` 已在前 72 詞，`management`、`parliamentary` 等抽象或專門字不會佔據入門區。

### 官方層級的優先順序

1. 編輯入門 300 詞。
2. 必要功能詞、MOE 1200 標籤剩餘詞與編輯選定生活補充詞。
3. MOE 800 標籤剩餘詞與日常延伸補充詞。
4. 尚未列入前帶的 CEEC 第 1、2 級詞，以及銜接補充詞。
5. 尚未列入前帶的 CEEC 第 3、4 級詞，以及中階補充詞。
6. 尚未列入前帶的 CEEC 第 5、6 級詞，以及專門或進階補充詞。

`sourceTags` 是來源，`difficultyBand` 是應用端套用 `bands` 後的編排，不應互相覆寫。MOE、CEEC 重疊時先採較早的 MOE 分組；功能詞允許編輯提前，仍留下來源標籤與理由。現有正規化詞庫的 MOE 1200／800 標籤分別有 1,209／794 個目標；印刷詞條的拆分與拼字合併後數量，不必等於名稱中的整數。

### 補充詞怎麼插入

845 個補充目標保留為同樣的總數：原 845 詞移除 13 個重複拼字，再新增 13 個不同目標。全部補充詞分散於六帶，不另外放到最後數關。

- 先檢查本詞採用的意思，以及是否為基本功能詞、具體生活物品或日常動作；必要的代名詞、助動詞、順序詞與具體生活詞提早安排。
- 一般頻率不能掩蓋專門語意。例如 `parish` 移到中階延伸，`parliamentary`、`plaintiff`、`antibody`、`quantum` 留在進階帶；`aeroplane`、`colourful`、`telly` 等透明生活詞較早出現。
- 未編輯指定的補充詞使用 ECDICT 正值 BNC／FRQ 名次的較小值：名次 ≤ 2,000 為第 4 帶，≤ 8,000 為第 5 帶，其餘為第 6 帶。缺少頻率視為最後；純頻率不會直接把詞放進前 3 帶。
- 第 2–6 帶內依相同的頻率值排序，同值依詞形、ID。第 1 帶依已公開的編輯主題順序。

BNC／FRQ 是一般語料常見度，會受語域及多義詞影響，不是兒童習得年齡。編輯判定已存入 `rationales` 與 `notes`，不宣稱已經真人教師逐詞驗收或實證校準。

移除的 13 個獨立目標原本全為 `supplement-ecdict`。保留美式主詞形並登記英式別名，避免把同一個拼字變體計成兩個已學單字。新增的 13 個目標為：`me`、`my`、`him`、`us`、`them`、`theirs`、`sunscreen`、`postcode`、`smartphone`、`headphones`、`username`、`checklist`、`earbuds`。

本波只合併上述 13 組，並未宣稱已統一所有英美拼字或地區用詞。其餘詞形由既有別名政策處理；若日後再合併，必須同時補足新的不同目標並驗證總數。

## 遊戲與存檔邊界

- 仍為 100 關、740 個任務；第 1–20 關每關 60 詞，第 21–40 關每關 40 詞，第 41–80 關每關 83 詞，第 81–100 關每關 84 詞。
- 第 20／40／100 關仍是累計 1,200／2,000／7,000 詞的遊戲里程碑；它們不是官方清單完成度的保證。入門 300 詞恰好覆蓋前 5 關。
- 本資料完整保留前 60 ID／順序。第 2 關以後的關卡內容有重排，整合端仍須處理舊存檔中後續關卡完成狀態；不能只因 ID 沒變就宣稱所有關卡存檔完全相容。
- 13 個被合併 ID 的舊學習紀錄，整合端應透過別名映射轉到保留 ID，避免學習統計重複計數。

## 本波驗證

- 7,000 個唯一 ID，和「原詞庫 − 13 個舊 ID ＋ 13 個新 ID」完全相同。
- 每個 ID 都有 1–6 的難度帶與可追溯的理由。
- 前 60 個 ID 和順序逐一相等。
- 6 個難度帶全程非遞減，沒有倒退的例外。
- 必要功能詞最晚在第 1,321 詞，全部早於第 2,000 詞。
- 845 個補充目標分散各帶；13 組別名都有存在的保留目標。
- 13 個新增詞的例句皆含完整目標，欄位及編輯來源齊全。
- 原官方來源的 6,162 列以本詞形或保留別名全數覆蓋。

驗證使用目前 `vocabulary.js` 的 7,000 詞快照、兩份新 JSON，以及 `sources/official-primary-headwords.json`。官方來源 6,162 列透過正規化詞形與既有別名全部涵蓋；其中 6,155 個為正規化後的官方學習目標，再加 845 個補充詞，合計 7,000。

本波檢查範圍為資料集合、順序、難度帶、基本功能詞位置、詞形合併與例句目標。應用程式、完整 build、瀏覽器呈現、學生試用與正式站部署不在這份驗證的範圍。
