# 2026-10-04 四角色評估修正

## 本波契約

保留既有 Google 登入、帳號隔離與 7,000 字主線進度。修正判分公平、漸進拼字提示、未完成續作、可調批次、複習安排、自由選章、閱讀與運用紀錄。這是產品改善，不宣稱真人學習成效。

- 拼字加上遮空例句、詞性、長度。詞目／別名仍為目標正答；同詞性短義重疊的另一詞視為歧義，提示目標後再練，不直接判錯或當成目標掌握。繁中與英文一致。
- 聽音、首字母、缺字提示寫入草稿事件；答案揭露前先保存作答。重新載入不洗掉提示／錯答。提示正答不增加首答成功或熟練。
- 3／5／10 字批次；完成後每字只給一次10 XP。原十字小關保留為地圖路標。舊v2存檔相容，短批次以questBatches驗證連續取得。
- 草稿以事件重播驗證，含相關複習前態及指紋，上限60,000字元。進度已在另一分頁前進或草稿損壞時不套用，不修改已學紀錄。正常新字卡、作答及提示可續作。
- 到期優先；完成章節按鈕僅複習本章。首頁提供到期入口、最近到期時間、曾錯字；行囊列出下次到期與載入更多。
- 起點檢核只採9字小樣本，回傳練習建議，不當正式程度評定；自由選章可指定詞序並接續下一批，不增加主線已學、XP或熟練。
- 首章有2題主線客觀理解與path/beside/is made of支援；100章都可保存主線解讀和原文引句。只核對引文，開放解讀由學習者／教師檢核。
- 第一批生活詞有另外編寫的句子支援；其餘目標可寫新句與情境說明，明示非自動文法評分。運用紀錄依章節與目標字識別，不把別批答案帶入。
- 理解／運用／檢核獨立保存最近20筆，與XP分開；放在既有帳號冒險資料中。相同帳號合併活動紀錄，不覆蓋另一裝置新增活動。登入套用或帳號切換會關閉舊練習對話窗。
