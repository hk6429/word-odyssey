# 語音來源與使用方式

Word Odyssey 參考「字鬥英雄」（`vocab-duel/js/speak.js`）的「預先產生的站內單字音檔優先，裝置語音備援」做法，重新實作可停止的播放器。沒有新增語音生成、遠端字典音檔服務或錄音功能。

## 來源與範圍

- 2026-10-03 從同一工作區的 `vocab-duel` 複製現有音檔。
- 原始對照表：`vocab-duel/data/audio-map.json`；原始音檔：`vocab-duel/audio/words/{id}.mp3`。
- 原始來源說明：`vocab-duel/licenses/assets.yml` 中 `kokoro-word-audio-v1`，以及該專案的 `copyright.html`。
- 僅複製 Word Odyssey `vocabulary.js` 7,000 個詞項實際匹配的 **6,148 個單字、6,148 個 MP3**，合計 **56,587,424 bytes**。其餘 **852 個單字**由裝置語音朗讀。
- 複製時逐檔比對來源與副本 SHA-256；完整檔案大小與雜湊記錄在 `docs/audio-inventory.json`。測試也會重新驗證全部落地檔案。
- 執行期對照表是 `audio-manifest.js`，音檔位於 `audio/words/`；皆位於 Git 忽略的 `data/` 之外。

## AI 語音揭露

這些是 **AI 合成語音，並非真人錄音**。來源專案記載使用：

- 模型：`hexgrad/Kokoro-82M`。
- 模型版本：`f3ff3571791e39611d31c381e3a41a3af07b4987`。
- 模型授權：Apache-2.0。Word Odyssey 散布既有產出音檔，沒有散布模型權重或離線生成工具。
- 主要音色：`af_heart`，屬於**美式英語**；不是英式語音。
- 來源資料另記載少數複核檔使用 `af_nicole`、`am_adam`、`af_bella`、`am_fenrir`；複製時保留來源的目前版本，沒有重新合成或更改聲音。
- 來源離線管線：Misaki（Apache-2.0）與 espeak-ng 備援（GPL-3.0）；這些工具不隨本站散布。

站內英倫視覺設定不代表音檔採英式口音。語音偏好清楚區分：

| 偏好 | 已收錄單字 | 未收錄單字、例句、文章 |
| --- | --- | --- |
| 自然語音 / Natural voice | 優先播放美式 AI MP3；失敗後使用裝置英語語音並提示 | 裝置英語語音 |
| 英式語音 / British voice | 一律使用裝置 `en-GB` 聲線 | 一律使用裝置 `en-GB` 聲線 |

若沒有 `en-GB` 聲線，顯示安裝聲線或改選自然語音的提示，不以美式聲線冒充英式語音。聲線清單延後載入時監聽 `voiceschanged`，最多等待 1.5 秒後回報缺聲；下一次操作仍會重新取得清單。

## 介面與播放控制

- 語音偏好與速度控制同時提供在主頁與課程對話框內，文字隨現有繁中／英文模式切換；偏好儲存在目前裝置。
- 可朗讀字卡、單字行囊、故事的情境單字、例句與完整英文故事。
- 正常速度：MP3 為 1.0 倍速，裝置 TTS 為 0.9；慢速兩者均為 0.8。
- 全文依英文句子逐句朗讀，過長句子再分段，按停止後不會繼續後續句子。
- 新播放會停止上一段，切換頁面／單字／課程、關閉課程、離開或隱藏分頁也會停止。
- 音檔失敗、裝置不支援、缺少英語或英式聲線、TTS 播放失敗都有對應的雙語提示。
- 本站不錄製、下載或再散布裝置 TTS 的聲音。裝置語音是否需要網路，由瀏覽器／作業系統的聲線決定。

## 驗證與限制

`node --test tests/voice.test.js tests/story.test.js` 驗證音檔完整性、覆蓋範圍、MP3 優先與失敗備援、延後載入聲線、嚴格英式選聲、停止競態、逐句播放與完整雙語標籤。

檔案雜湊相符代表複製完整，不等於每字發音已經人工複核。單一音檔無法區分多音字（如 read、live、tear）的語境；例句與文章品質也依裝置語音而異。此版沒有逐字重新人工聽審，不能宣稱所有聲音一致、具真人教師認證或達成學習成效。
