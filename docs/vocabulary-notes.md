# 7,000 個學習目標的來源與編排

1,200、2,000、7,000 是自編課程的累計學習里程碑，不是「官方精確 7,000 字」。官方 PDF、抽取方法與使用條件見 [來源研究](corpus-research.md)。

## 收錄與計數

教育部英語文課綱與大考中心參考詞彙表共有 6,162 個原始主詞拼法，經既有 7 組別名正規化後為 6,155 個官方來源目標，再加 845 個補充目標。官方主詞可由 `id` 或 `aliases` 找回；片語算一個目標，這不是嚴格語言學詞元數。

本版再把補充詞中的 13 組英美拼字變體合併為既有目標的別名，例如 colour／color、centre／center、theatre／theater；空出的名額補入 me、my、him、us、them、theirs、sunscreen、postcode、smartphone、headphones、username、checklist、earbuds。總數仍為 7,000，官方來源完整保留。拼字練習接受所記錄的別名。

`sourceTags` 表示實際來源：moe1200、moe800、ceec-1 至 ceec-6、supplement-ecdict 或 supplement-editorial。來源標籤不等於網站關卡。

## 難度與關卡

詞序依六個連續難度帶安排：生活入門 300 詞 → 國中核心 → 國中延伸 → 高中銜接 → 高中中階 → 高中進階。完整規則、詞序範圍與例外理由見 [課程排序](curriculum-order.md) 與 `sources/curriculum-order.json`。

前 300 詞為專案編選的生活準備詞，不冒稱官方唯一的國小 300 字表。第 2–6 帶結合官方來源分級、必要功能詞與語料詞頻；專門詞不因一般詞頻較高就自動排入初階。補充詞按意思與使用情境分散各帶，不全部堆到最後。

| 大章節 | 每章新目標 | 區段累計 |
|---|---:|---:|
| 1–20 | 60 | 1,200 |
| 21–40 | 40 | 2,000 |
| 41–80 | 83 | 5,320 |
| 81–100 | 84 | 7,000 |

100 個大章節拆為 740 個最多 10 字的小關。難度帶可穿越章節邊界；第 20／40 章的里程碑不能解讀為官方清單恰好逐項收完。完整來源涵蓋與當前延後詞清單記錄於 `vocabulary-audit.json`。

## 主要義、例句與英英釋義

初始字典資料來自 ECDICT，中文經 OpenCC s2twp 轉為臺灣繁體。本版優先以具體例句決定主要意思與詞性，再對齊中文短義、英文釋義及中譯，避免 bank、match、record 等同詞性異義混配。

既有字鬥英雄自編素材有 6,150 個原詞目匹配，原始缺漏 850 個另行補撰；之後合併 13 個拼字目標並新增 13 個詞。來源筆數是正規化之前的紀錄，最終有效數量及 SHA-256 見 `lexical-enrichment-audit.json`，不把不同階段的數字相加灌水。

每個有效詞目均提供例句、中譯、對應詞形及來源。703 個已知詞性義項問題與其餘 5,167 個字典義項分批依例句修訂；校訂檔保留於 `sources/curated-*.json`。模型逐筆處理與格式／抽樣核對不等於真人教師全量語義審查。

原始字典音標混用不同系統，未將它們當作已審訂 IPA 呈現。lead、bow、minute、read 等已知多讀音字以例句朗讀提供脈絡；其餘音訊政策見 [語音來源](audio.md)。

每大章節有三個直接取自當關詞表的閱讀任務，共 300 個目標與原句。其餘詞目仍在字卡提供自己的例句。

## 重建與來源

```sh
uvx --from opencc-python-reimplemented==0.1.7 python scripts/build-vocabulary.py
```

Python 先從固定本機快取產生基礎詞庫，再執行 `scripts/enrich-vocabulary.mjs` 套用校訂、拼字合併與難度詞序，最後由 `scripts/build-missions.mjs` 重建當關閱讀任務。網站執行不需 Python、外部字典或即時 AI API。

主要輸入為官方主詞、ECDICT 快取、種子教材、字鬥英雄例句、分批校訂 JSON，以及課程排序／替換 JSON。audit 記錄輸入與產出的 SHA-256，保留來源計數及限制。

## 進度與品質邊界

前 60 個 ID 及順序維持原樣；發布前只讀查詢的本機帳號最大進度為 10 字，因此目前帳號記錄不受第二章以後的重排影響。此版為首次公開發布；更早開發版超過第一章的備份不宣稱完全相容，應先保留原備份。

難度帶是課程編排，不能當作 CEFR、年齡能力或學習成效認證。例句與主要義仍可因教學情境持續校訂；非空、唯一性與數量驗證不代表教學品質已經全面驗收。
