# 7,000 個學習目標的來源與編排

本網站的 **1,200、2,000、7,000** 是自編課程的累計學習目標，不能稱為「官方精確 7,000 字」。來源抽取方法、官方 PDF 連結及使用條件見 [corpus-research.md](corpus-research.md)；本文件描述實際生成流程。

## 收錄與計數

- 教育部英語文課綱及大考中心參考詞彙表聯集有 **6,162** 個原始主詞拼法；合併 7 對已確認同義的拼法後，保留 **6,155** 個官方來源學習目標。原始主詞全部能由 `id` 或 `aliases` 找回。
- 再從 ECDICT 的字典及詞頻資料選取 **845** 個不同的延伸字詞，合計 **7,000** 個大小寫不敏感的唯一字串。
- 官方來源的括號補充形式不另計，斜線形式取第一項；完整片語算一個學習目標。原始來源紀錄留在 `sources/official-primary-headwords.json`。
- 計數單位是「學習目標」，不是嚴格語言學詞元。已將 `O.K./OK`、`o’clock/o'clock`、`e-mail/email`、`good-bye/goodbye`、`hair dresser/hairdresser`、`am/a.m.`、`pm/p.m.` 各合併為一個目標；候選 `cafe` 也併為 `café` 的別名。`am/a.m.` 與 `pm/p.m.` 在大考中心原表均標為時間副詞，因此此處不採字典誤配的元素、政府職銜或 be 動詞義。每組拼法保留於 `aliases`，所有官方來源標籤取聯集。
- `sourceTags` 記錄實際來源，`moe1200`、`moe800`、`ceec-1` 至 `ceec-6` 是原表分組；`supplement-ecdict` 是延伸字。標籤與網站關卡不同。

## 100 關分配

| 關卡 | 每關新目標 | 此段目標 | 累計 |
| --- | ---: | ---: | ---: |
| 1–20 | 60 | 1,200 | 1,200 |
| 21–40 | 40 | 800 | 2,000 |
| 41–80 | 83 | 3,320 | 5,320 |
| 81–100 | 84 | 1,680 | 7,000 |

1. 教育部基本表抽取後有 1,209 個主詞。前 1,200 從合併後仍有 `moe1200` 標籤的詞條選取，優先安排既有種子教材，再按可用 BNC 詞頻排序；剩餘 9 個基本詞安排在第二階段。
2. 其餘教育部主詞依基本表優先、詞頻在後的方式編排至第 2,000 個目標。教育部兩表共有 2,003 個主詞，最後 3 個接在第 2,000 個之後；完整延後清單見 `vocabulary-audit.json`。
3. 其餘官方主詞按大考中心級別排序，同級再按 BNC 詞頻及字母排序；MOE 尚未收完的 3 個先補回。
4. 最後加入 845 個延伸字。延伸詞依候選 BNC 詞頻排序；沒有把詞頻誤標為官方難度級別。

## 中文義、詞性與例句

- 一般詞義來自 ECDICT，使用 **OpenCC 0.1.7 `s2twp`** 轉為臺灣繁體，再替換常見在地用語、移除領域標記與字典格式、保留至多兩個短義。
- 大考中心有指定詞性的目標，優先選該詞性的字典義，避免把 `shy`、`sharp` 等常見形容詞先解釋成罕用名詞。
- 基礎功能詞、月份、星期、專有名詞、常用片語及可辨認的錯義另外以腳本內的 `OVERRIDES` 修正；以 `meaningSource: editorial` 標記。既有 72 筆教材以 `meaningSource: seed` 標記，其餘為 `ECDICT`。
- `I`、月份、星期及專有名詞保留適當英文顯示形式；`id` 固定為小寫來源主詞。`may/May`、`march/March`、`china/China` 等在來源正規化時合併的字義，以短義及 `usageNote` 補充。
- 只保留原有 72 筆已撰寫的例句與翻譯。其餘目標的 `example`、`translation` 不存在；前端應在沒有例句時顯示字詞與詞義，不得替它補上假造的空泛例句。
- 延伸候選排除明顯髒話、性露骨詞義、縮寫、非一般單字及無可用中文義的項目；官方主詞則完整保留。候選篩選規則與排除紀錄可在腳本及 audit 查看。

**品質邊界：** 這是有來源、可追溯的字典詞義教材初稿；已做格式檢查、選定字義校訂及抽查，尚未逐一完成 7,000 詞的教師語義審查。字典排序、臺灣用語及適合特定年段的主要字義仍可能需後續校訂。自動繁體轉換、非空檢查和數量斷言均不等於全量教學驗收。

本次建置的中文詞義來源：**72** 筆種子教材、**307** 筆人工校訂、**6,621** 筆字典轉換，共 **7,000** 筆；全部含中文義、明確詞性及來源標籤，最長中文義 19 字。候選篩選與排除紀錄見 audit。這些數字代表資料建置與抽查紀錄，不代表 7,000 詞逐條完成教學驗收。

## 英英釋義

全部 **7,000／7,000** 筆都有非空、無中文字的 `definition`。其中 **286** 筆是專案撰寫的簡明英文，包括全部 72 筆種子教材、缺少來源釋義的片語、基礎功能詞，以及來源只有名詞義但中文教的是動詞的項目；其餘 **6714** 筆取自 ECDICT。

生成器優先挑選與顯示的第一詞性相同的一個英文義項，移除 `n.`、`v` 等字典詞性代碼，不再把頭兩行不相關的義項串在一起。長釋義優先選完整的短分句，目前最長 311 字元。`definitionSource` 分別標記 `editorial` 或 `ECDICT`，可追溯到 `scripts/english-overrides.json` 或來源快取。

這些檢查保證欄位完整、明顯詞性錯配已處理，以及種子教材的主要義一致；**不等於 7,000 筆都完成教師逐條語義審查**。字典第一義即使詞性相同，也仍可能與中文短義不完全對應，需持續校訂。前 1,200／2,000 也是依官方標籤和詞頻編排的課程，不是原表的逐項精確重現。

## 離線重建與驗證

在專案根目錄執行：

```sh
uvx --from opencc-python-reimplemented==0.1.7 python scripts/build-vocabulary.py
```

`uvx` 初次執行可能下載建置依賴；**生成腳本只讀取本機來源快取**。網站執行時直接載入 `vocabulary.js`，不需 Python、外部字典、API 金鑰或即時 AI。

固定輸入：

- `sources/official-primary-headwords.json`
- `sources/ecdict-official-matches.json`
- `sources/ecdict-supplement-candidates.json`
- `seed-words.js`
- `scripts/build-vocabulary.py`
- `scripts/english-overrides.json`

輸出：`vocabulary.js` 與 `docs/vocabulary-audit.json`。腳本檢查精確 7,000 筆、ID 及英文顯示字串大小寫不敏感唯一、6,162 原始官方主詞由 6,155 個主詞或其別名完整涵蓋、845 延伸字、全部具有短中文義、英英釋義及來源標籤。audit 記錄每份輸入與輸出的 SHA-256、中文與英文詞義來源數量、別名對照、原始與合併後數量、例句數、里程碑及延後清單；不含時間戳，便於重建後逐位元組比較。

程式碼授權與語料使用條件分開處理；ECDICT 的 MIT 聲明在 `sources/ECDICT-LICENSE.txt`，官方詞表的使用條件請依 `corpus-research.md` 的原始來源說明。
