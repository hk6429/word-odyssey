# Word Odyssey 字旅

英倫彩色潑墨風格的英文學習網站。用 100 關串起累積 1,200、2,000、7,000 字的英雄之旅；每次最多學 10 個新字。

## 啟動

需要 Node.js 22.13 或更新版本（使用內建 SQLite）。

```sh
npm install
cp .env.example .env
npm start
```

開啟 http://localhost:8787 。可用 `PORT` 環境變數變更連接埠；`APP_ORIGIN` 必須與網址一致。未建立 `.env` 時預設 4186。這是本機預覽，尚未部署公開網站。

Google 登入使用 Google Identity Services：將 Google Cloud 網頁用戶端的公開 Client ID 放入 `.env` 的 `GOOGLE_CLIENT_ID`，並在該用戶端登記相同的 JavaScript origin。沒有設定時仍可使用訪客模式。不要把 client secret、服務帳戶金鑰或 `.env` 提交至 Git。

## 學習結構

| 關卡 | 每關新字 | 關卡結束累積 |
| --- | ---: | ---: |
| 1–20 | 60 | 1,200 |
| 21–40 | 40 | 2,000 |
| 41–80 | 83 | 5,320 |
| 81–100 | 84 | 7,000 |

每關都有接受召喚、導師指引、跨越門檻、面對試煉、帶回力量五個步驟。大關拆成最多 10 字的小任務，共 740 個任務。

- 新任務開始前先複習全部到期字與上一任務單字；第一次出發無舊字可複習，直接認識新字。
- 新字卡後以字義選擇、拼字練習試煉。錯題重排，直到答對才前進。
- 小任務全部完成才保存新字，每個新字一次給 10 XP。重做或純複習不重複給分。
- 「已學」與「熟練」分開；熟練需三次到期、首次答對的複習。這是練習紀錄，並非能力認證。
- 完成目前關卡全部單字才能解鎖下一關。未完成的小任務可重新練習，已完成任務保留。
- 單字行囊可搜尋、篩選到期與熟練字；成長手札可匯出、匯入備份。

## 詞表與素材

本專案的 7,000 是自編課程的唯一學習詞目數，不是將教育部與大考中心詞表直接相加，也不是宣稱官方原表恰有 7,000 詞條。

詞表來源與計數規則見 [來源研究](docs/corpus-research.md)、[課程詞表說明](docs/vocabulary-notes.md)、[資料稽核](docs/vocabulary-audit.json)。6,155 個合併官方詞條與 845 個延伸詞，共 7,000 個；異體拼法列為別名，不重複灌入學習進度。前 1,200／2,000 為依臺灣詞表安排的自編課程順序。

全部詞條都有中文與英英釋義；中文由開放授權字典轉為臺灣繁體並做定點修正。72 個起步單字附原創例句，其餘詞條不捏造例句。未完成全數人工逐字教學審訂。

介面、操作提示、釋義、故事與回饋可切換繁中／全英。三個角色各有敘事回應；劇情選擇累積好奇、勇氣、善意，早期選擇會在後續回應。劇情不代替單字測驗，不會靠點擊故事跳過關卡。

100 篇閱讀由短句、對話逐步增加至約 88–106 字的文章，提供朗讀、原文填空與原句證據。後 60 篇採區域共同開場、每關獨立事件、輪替反思，不是 100 篇完全獨立的長篇作品。閱讀情境字不等於已涵蓋全部 7,000 詞的例句；詳見 [故事與圖像](docs/story-art-prompts.md)。

英倫插畫以內建 imagegen 產生；章節圖以每張 10 格的圖集呈現，100 個章節畫面不是 100 個圖片檔。見 [主視覺來源](docs/art-prompt.md) 與 [章節圖提示](docs/chapter-art-prompts.md)。

冒險地圖另有 10 張完整區域地景，每 10 關切換一張，包含科茲窩、牛津、倫敦、劍橋、約克、湖區、峰區、愛丁堡、蘇格蘭高地與歸途。手機以局部左右捲動保留完整風景與可讀路標；詳見 [地圖素材與驗證](docs/map-qa.md)。

## 儲存與隱私

訪客進度存於瀏覽器 localStorage。登入後，伺服器驗證 Google ID token，使用 HttpOnly、SameSite session cookie，依 Google 帳號儲存單字進度、角色、故事選擇與語言偏好。資料庫位於 `data/progress.sqlite`，不提交至 Git。HTTPS 環境會加上 Secure cookie。

目前伺服器只綁定本機；真正的跨裝置使用仍需部署同一個可公開存取、具有持久資料庫的伺服器，並登記正式 origin。把靜態檔單獨上傳不會啟用登入儲存。網站不索取 Google Drive／Gmail 權限。

更換環境前可匯出 JSON 備份；匯入會明確確認是否取代目前旅程。登入同步以較完整的學習進度合併；較短的匯入檔不會抹掉伺服器的已學進度。

多分頁透過 storage 事件同步；儲存前比較舊快照，支援 Web Locks 的瀏覽器會序列化寫入，避免舊分頁覆蓋新的學習成果。測試網址 `?test=1` 使用獨立測試存檔。

語音參考「字鬥英雄」：6,148 個單字使用站內 Kokoro AI 合成 MP3（主要為美式音色）；其他單字、例句與文章使用裝置語音。可選英式聲線、正常／慢速、停止。英式選項需裝置有 `en-GB` 聲線，缺聲時會提示。[語音來源與限制](docs/audio.md) 包含完整授權出處。語音不需付費 TTS API。

字型由 Google Fonts 載入，離線時使用系統字型。字彙與練習不依賴外部 AI API；裝置語音是否需要網路取決於所選聲線。
