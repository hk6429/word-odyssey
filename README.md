# Word Odyssey 字旅

正式網站：[word-odyssey.hk6429.workers.dev](https://word-odyssey.hk6429.workers.dev)

英倫彩色潑墨風格的英文學習網站。用 100 關串起累積 1,200、2,000、7,000 字的英雄之旅；每次可選 3、5 或 10 個新字，並可接續未完成練習。

## 啟動

需要 Node.js 22.13 或更新版本（使用內建 SQLite）。

```sh
npm install
cp .env.example .env
npm start
```

開啟 http://localhost:8787 。可用 `PORT` 環境變數變更連接埠；`APP_ORIGIN` 必須與網址一致。未建立 `.env` 時預設 4186。本機預覽與正式 Cloudflare Workers 使用同一套前端及進度契約。

Google 登入使用 Google Identity Services：將 Google Cloud 網頁用戶端的公開 Client ID 放入 `.env` 的 `GOOGLE_CLIENT_ID`，並在該用戶端登記相同的 JavaScript origin。沒有設定時仍可使用訪客模式。不要把 client secret、服務帳戶金鑰或 `.env` 提交至 Git。

## 學習結構

| 關卡 | 每關新字 | 關卡結束累積 |
| --- | ---: | ---: |
| 1–20 | 60 | 1,200 |
| 21–40 | 40 | 2,000 |
| 41–80 | 83 | 5,320 |
| 81–100 | 84 | 7,000 |

每關都有接受召喚、導師指引、跨越門檻、面對試煉、帶回力量五個步驟。大章節拆成最多 10 字的小關，共 740 個；十字小關作為地圖路標；每批可選3、5或10字，完成一批即保存，不必在同一天完成整章。小關路線用插畫卡呈現當前進度、下一站與完成印章。

- 新任務開始前先複習一輪到期字與上一任務單字，每輪最多 20 字；第一次出發無舊字可複習，直接認識新字。
- 新字卡後先做字義辨認，後續複習輪換辨認與拼字；拼字可用聽音、首字母、缺字提示。答對後短暫顯示回饋再自動前進；答錯保留解釋，錯題重排。
- 本批試煉完成才計入已學新字，每個新字一次給 10 XP。未完成練習另存草稿。重做或純複習不重複給分。
- 「已學」與「熟練」分開；熟練需三次到期、首次答對的複習，其中至少一次為主動回憶。這是練習紀錄，並非能力認證。
- 完成目前關卡全部單字才能解鎖下一關。未完成練習可接續字卡、題目與提示紀錄；已完成任務保留。
- 單字行囊可搜尋、篩選到期與熟練字；成長手札可匯出、匯入備份。

## 詞表與素材

本專案的 7,000 是自編課程的唯一學習詞目數，不是將教育部與大考中心詞表直接相加，也不是宣稱官方原表恰有 7,000 詞條。

詞表來源與計數規則見 [來源研究](docs/corpus-research.md)、[課程詞表說明](docs/vocabulary-notes.md)、[資料稽核](docs/vocabulary-audit.json)。6,155 個合併官方詞條與 845 個延伸詞，共 7,000 個；異體拼法列為別名，不重複灌入學習進度。前 1,200／2,000 為自編課程里程碑；詞序依生活入門、國中核心與延伸、高中銜接與進階共六帶安排，見 [排序說明](docs/curriculum-order.md)。

全部詞條都有中文與英英釋義；中文與英英短義依例句選定主要義項，來源字典原始資料保留以便追溯。全部 7,000 個詞條附例句與繁中對照；原始版本有 6,150 個詞可對應既有字鬥英雄自編素材，850 個缺漏另補撰；其後合併 13 組英美拼字並補入 13 個不同目標，最終有效數量見資料稽核。新增與修訂內容經模型逐筆處理與獨立抽查，未完成全數真人教師逐字教學審訂。

介面、操作提示、釋義、故事與回饋可切換繁中／全英。三個角色各有敘事觀察；十個區域各有三種選擇，會在後續章節與結局回收。劇情選擇累積好奇、勇氣、善意。劇情不代替單字測驗，不會靠點擊故事跳過關卡。

100 篇閱讀由短句、對話逐步增加至五句以上的故事文章，提供朗讀、原文填空與原句證據。每大章節另有三個來自當關詞表的旅途手札任務，共 300 個閱讀任務詞；其餘單字在學習卡提供例句。後段章節已加入各自的事件延續，並遵守角色出場順序。詳見 [故事與圖像](docs/story-art-prompts.md)。

英倫插畫以內建 imagegen 產生；章節圖以每張 10 格的圖集呈現，100 個章節畫面不是 100 個圖片檔。見 [主視覺來源](docs/art-prompt.md) 與 [章節圖提示](docs/chapter-art-prompts.md)。

冒險地圖另有 10 張完整區域地景，每 10 關切換一張，包含科茲窩、牛津、倫敦、劍橋、約克、湖區、峰區、愛丁堡、蘇格蘭高地與歸途。手機以局部左右捲動保留完整風景與可讀路標；詳見 [地圖素材與驗證](docs/map-qa.md)。

## 儲存與隱私

訪客進度存於瀏覽器 localStorage。登入後，伺服器驗證 Google ID token，使用 HttpOnly、SameSite session cookie，依 Google 帳號儲存單字進度、角色、故事選擇與語言偏好。本機使用 `data/progress.sqlite`；正式環境使用專案獨立的 SQLite Durable Object，依使用者 ID 分隔資料，進度壓縮保存。資料庫不提交至 Git；正式 Cookie 為 Secure。

正式入口是 Cloudflare Worker，API 與靜態素材在同一網址。Google 登入必須在沿用的網頁用戶端登記正式 origin。網站不索取 Google Drive／Gmail 權限。

更換環境前可匯出 JSON 備份；匯入會明確確認是否取代目前旅程。登入同步以較完整的學習進度合併；較短的匯入檔不會抹掉伺服器的已學進度。

多分頁透過 storage 事件同步；儲存前比較舊快照，支援 Web Locks 的瀏覽器會序列化寫入，避免舊分頁覆蓋新的學習成果。測試網址 `?test=1` 使用獨立測試存檔。

語音參考「字鬥英雄」：6,148 個單字使用站內 Kokoro AI 合成 MP3（主要為美式音色）；其他單字、例句與文章使用裝置語音。可選英式聲線、正常／慢速、停止。英式選項需裝置有 `en-GB` 聲線，缺聲時會提示。[語音來源與限制](docs/audio.md) 包含完整授權出處。語音不需付費 TTS API。

字型由 Google Fonts 載入，離線時使用系統字型。字彙與練習不依賴外部 AI API；裝置語音是否需要網路取決於所選聲線。

## Cloudflare 部署

```sh
npm run build
wrangler deploy
```

`wrangler.jsonc` 指向 `edge.mjs`，由專案獨立的 `ProgressStore` SQLite Durable Object 處理 `/api/*`。目前共用一個專案物件，SQL 依使用者隔離並以 revision 原子比較更新；不是每位使用者各建一個物件。靜態輸出只包含白名單前端與素材，`.env`、資料來源與伺服器程式都不公開。需先確認 Cloudflare 登入狀態及 Google 正式 origin。

新增的小關插畫為 10 張 3×3 區域圖集，共 90 幅區域情境，依地區搭配於 740 個小關，會重複使用，並非 740 幅各自獨立生成的插畫。起步十字另有專屬情境圖集。

公開網站使用 34 張 WebP 圖片，約 22.3 MB；原 PNG 共約 122.6 MB，保留作為素材來源，不放入正式靜態輸出。參數與逐檔大小見 [圖片傳輸紀錄](docs/image-delivery.json)。

首次正式發布使用 SQLite Durable Object。已完成真實 Google 登入，並將原本 10 字、100 XP 的本機學習備份匯入；重新載入後的伺服器回應仍為 10 字。發布版本與靜態檔雜湊見 [正式站讀回](docs/production-readback.json)。

## 四角色評估後的練習支援

首頁可設定批次、先複習到期字、接續草稿與檢核起點。自由選章可從指定詞序分批練完整章；這些檢核和主線理解、新情境運用另存紀錄，不授予XP或熟練。首章有客觀理解題，各章開放解讀只核對引文，仍需自評或教師回饋。詳見 [修正契約與驗證](docs/learning-review-fixes.md)。

## 選擇題鍵盤操作

A：← 或 1；B：↑ 或 2；C：↓ 或 3；D：→ 或 4。依畫面選項順序作答；題目未提供的選項不接受按鍵。答對直接進入下一題或完成畫面，答錯停留解析，讀完再按繼續。輸入框、選單、中文／日文輸入法組字與系統快捷鍵不攔截；長按與雙擊不連續作答。

## 大關、小關與故事進度

旅途中可查看所在大關、已完成的小關清單及剩餘題數／步驟。一次練習批次完成不等於整個小關過關；複習、重試和略過不增加過關數。故事以「前情、這次的任務或結果、接下來」銜接，完整過關後才揭露下一段結果。所有進度由原有存檔推算，保留既有學習紀錄。

### 滿版故事場景（2026-10-04）

首頁以滿版風景、人物與故事對話呈現，關卡目錄和小關完成清單收進可展開的選單。學習畫面延續風景背景；既有存檔、進度、語音和選擇題快捷鍵不變。桌機與手機驗證截圖位於 `docs/fullscreen-desktop.png` 與 `docs/fullscreen-mobile.png`。

### 沉浸閱讀與點選練習

故事、小關練習與文法使用滿版場景。100 章閱讀提供逐題選擇、詞義配對與原文片段排序；答對直接前進，答錯停留解析。舊有開放閱讀紀錄仍可查看，進階寫作收為選做。單字回想可以選用「點字母拼排」，依提示練習計分，不冒充獨立拼字成功。

第一區新增九幅完整尺寸插畫，其他區域沿用既有區域場景，並非 740 小關各有一幅獨立插畫。插畫提示詞與路徑見 [quest-scene-prompts.json](docs/quest-scene-prompts.json)。
